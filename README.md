# SombrasDelTriunfo
"Sombras del Triunfo" is an Augmented Reality game developed for mobile as the bachelor's thesis in my Computer Science degree. This game' scenarios are real life places where all the elements are placed using geospatial location. For that reason, sadly this game is only playable in Granada, Spain. The main goal of the game is gathering all the vaccines' ingredients scattered along the city and place them into a special machine. However, every place you can find an ingredient at will have zombies trying to kill you. To defend yourself you will have different weapons. Killing zombies and gathering ingredients will give you money that you can use in the shop to buy ammunition and upgrade your weapons.
